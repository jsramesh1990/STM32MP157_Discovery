# Contributing to STM32MP157 Energy-Aware Sensor

Thank you for contributing to the STM32MP157 Energy-Aware Sensor project.

This project focuses on low-power embedded systems using the STM32MP157,
Cortex-A7, Cortex-M4, Linux/OpenSTLinux, Yocto, RPMsg/OpenAMP, sensors,
power management, and energy-harvesting concepts.

---

## 1. Project Goals

Contributions should support one or more of the following areas:

- STM32MP157 board support
- OpenSTLinux / Yocto BSP
- Cortex-A7 Linux applications
- Cortex-M4 firmware
- RPMsg / OpenAMP communication
- Sensor interfaces
- Device Tree configuration
- Low-power operation
- RTC/GPIO wake-up
- Power measurement
- Energy harvesting
- Automated testing
- Documentation
